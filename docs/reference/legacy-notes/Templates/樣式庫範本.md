# 樣式庫(範本)

用途:把你喜歡的字卡、特效、整體風格收成一份清單,剪片時**說編號**就好,例如「整體用 S1,再加 R03 聚光燈」。
每新增一個,編號接續;每個一定要有**狀態**,尤其是「做不到」和「你不要」。

狀態:✅ 已實作並用在成片 / 🖼 只有示範圖 / 🟡 可做(還沒做)/ 🔴 做不到或測試失敗 / ⛔ 使用者不要

## 一、整體風格(選一個當基底)
| 編號 | 名稱 | 長相 | 來源 | 狀態 | 預覽 / 做法 |
|---|---|---|---|---|---|
| S1 | (例:暖色手帳風) | 奶油紙、手寫字、淡色標籤 | 你的描述 | 🟡 | 示範圖路徑 |
| S2 | (例:黑底半透明卡) | 黑色半透明圓角卡、奶油襯線字、橘色強調 | 你的選擇 | 🟡 | |

## 二、元件(可用在任何整體風格)
| 編號 | 名稱 | 說明 | 狀態 |
|---|---|---|---|
| C01 | 取景框角標 | 畫面四角的細線 L 形 | 🟡 |
| C02 | 章節圓點 | 上方一排「01 02 03」,目前章節用重點色 | 🟡 |
| C03 | 章節卡 | CHAPTER nn + 大標題 + 細線 + 副標,左上,約 2 秒 | 🟡 |

## 三、特效與字卡
| 編號 | 名稱 | 長相 | 來源 | 狀態 | 做法備忘 |
|---|---|---|---|---|---|
| R01 | 聚光燈 | 背景變暗,主角用圓形露出 | 參考貼文 | 🟡 | 全幅暗化 PNG,中間挖透明圓;位置逐鏡頭手調 |
| R02 | 打勾清單卡 | 圓角卡內 ✓ 項目 | | 🟡 | PNG |
| R03 | 說話字幕 | 圓潤手寫字 + 發光 + `\ … /` 斜線 | | 🟡 | 每句一張 PNG |

## 四、動畫(先講限制)
| 名稱 | 狀態 | 說明 |
|---|---|---|
| 淡入淡出 | ✅ | 疊圖的 `anim: fade` |
| 彈出縮放 | 🔴 | 用時間運算的縮放不正確,目前 = 固定大小 + 淡入 |
| 逐字跳出 | 🟡 | 要多張 PNG 輪流顯示,尚未測 |

## 五、你確認的偏好(跟著所有風格走)
- (例:字卡風格要一致,黑底半透明為主)
- (例:字不要黑外框,白字靠陰影或半透明底襯托)
- ⛔ (例:標題不要殘影,看著不舒服)

## 六、怎麼換(給之後的對話)
1. 說整體風格編號與要加的元件、特效編號,例如「S2 + R01 用在第 12 個鏡頭」。
2. 新風格:先做**示範圖**給你核對,通過再套進分鏡。**不要一次改很多版本。**
3. 套進成片前,逐鏡頭抽格確認字卡**不蓋臉**、不蓋平台按鈕區。
4. 新參考:分析後在這裡新增一列,附來源與狀態。
