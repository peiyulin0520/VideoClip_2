# 溝通與審核方式

做了好幾支片之後,**來回最多的地方**其實都是溝通,不是技術。以下是實際有效的解法。

## 一、最容易來回的四個地方

1. **審美只有形容詞、沒有參照**(「粗糙」「不舒服」「都還好」)。AI 只能猜,猜錯就是一輪。
2. **AI 只看得到靜止畫面**:節奏、聲音、動畫看不到;認人、判斷素材內容也容易錯。
3. **一句話有兩種讀法**(例:「第三張照片」是影片裡的第三張,還是上傳順序的第三張?)。
4. **AI 回得太長、太多表格**,你看不懂。

## 二、真正有效的做法

- **你給具體證據**:截圖、參考連結、一句更正。截一張原片的字,比說「不好看」有用十倍。
- **AI 先做看得到的東西**:示範圖、對照圖、定格,不要只用文字描述。
- **給有限選項**:A/B/C 或四選一,你一個字就能決定。
- **一次只改一個變數**:斜線生硬就只改斜線,字型沿用,不重做整份。
- **有安裝、下載的事**:先查官方來源,列清單,等你同意。

## 三、AI 該遵守的(已寫進 AGENTS.md)

1. 不確定就問一句,**不要猜兩次以上**。同一件事試 2–3 次還不對,就停下來問你要參照。
2. **認人、認內容前,先做對照圖請你核對標準**,不要自己下結論;結論寫進 `進度.md`。
3. 每次都講清楚「我只看了靜止畫面」。
4. 回覆短、白話、一次一件事。結尾只留一個問題,附選項。
5. 你的話有兩種讀法時,先用一句話確認它的理解,再動手。
6. 你的每個修正都寫進 `進度.md`,避免換對話後重犯。

## 四、對照圖/定格/示範圖的固定格式(建議)

目的:你不用想「這張圖在比什麼」,一眼就看懂。

- **同一個畫面、同一個版型,只改一個變數。** 每格標 A、B、C(不要用文字描述代替)。
- **對照圖**:左右或上下並排,每格下面一行短說明(例如「A 現在」「B 加粗」)。
- **定格**:標出來自影片的第幾秒;如果疊了字卡,同時給一張沒疊的。
- **示範圖**:用示意素材(漸層、測試圖),**不用真人臉**,除非你同意。
- 圖下面只放一個問題,例如「請在下面選 A / B / C」。

## 五、「點一下就能選」的決策頁(可選)

我們原本用一個網頁讓使用者點選,不用打字回覆。**那個網頁用的是 Claude 的功能,Codex 沒有**,所以改成這兩種:

**做法 1(最簡單、最安全,建議):** AI 產生一個**本機單一 HTML 檔**,你在瀏覽器打開,點選後頁面下方會產生一段文字(例如「第 3 題選 B、第 5 題其他:再圓一點」),你按「複製」貼回給 Codex。**不需要伺服器、不連網、不存任何資料。**

**做法 2(比較複雜,不建議一開始就做):** 在自己電腦跑一個只開在 `localhost` 的小程式接收答案。這會多一個要檢查安全的東西。

頁面規格:
- 每題:題目、(選填)圖片、一組選項按鈕、**一定要有「其他」讓你打字**。
- 手機也要能點(按鈕夠大)。
- **圖片只放示意圖或你明確同意的畫面**,不放家人和小孩的臉。
- 頁面不放任何你的個人資料、不引用外部網站的腳本。

## 六、對你自己的建議

- 看過成片後,**一次把要改的地方講完**(第幾秒 + 哪裡不對)。
- 說不清楚時,**丟一張截圖或一個參考連結**,比形容詞好用。
- 你討厭的,也要說(例如「不要殘影」「不要太花」)。AI 會寫進風格檔,之後不再犯。
