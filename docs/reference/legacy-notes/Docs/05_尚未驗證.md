# 尚未驗證:請當成未知

這份教學包的作者是在 **Windows + Claude Code** 上做出來的。以下這些,**沒有人在你的環境(Mac + Codex)測過**:

## 環境
- [ ] Homebrew 的 `ffmpeg`、`whisper.cpp` 在你的 Mac 上能不能裝、版本是多少、指令名稱是不是 `whisper-cli`。
- [ ] 你的 Mac 是 Apple Silicon 還是 Intel(影響預編譯版本與速度)。
- [ ] whisper.cpp 在 Mac 上跑多快、準不準(繁體中文口播)。
- [ ] Codex 能不能照 `AGENTS.md` 的流程與溝通規則做(Codex 的行為可能和 Claude Code 不同)。

## 工具
- [ ] render 腳本:原本是 Windows PowerShell,**Mac 要重寫**(Python 3 或 shell);分鏡 JSON 的格式與每個欄位的意思在 `templates/分鏡範本.json`。
- [ ] 字卡疊圖(PNG 疊在影片上):做法是 ffmpeg 的 `overlay`。字卡 PNG 要自己做(Mac 上可用 Python 的圖像函式庫、或用瀏覽器畫完截圖),**原專案用的是 Windows 專用的畫圖元件,不能用。**
- [ ] 轉場(`xfade`)、顆粒、暗角等:在 ffmpeg 內建,**我們只在 Windows 版測過預覽,沒有接進輸出流程。**

## 我們自己也還沒做到的
- 逐字跳出的字幕、字卡彈跳動畫(要逐格輸出,或用專門做動畫的工具,例如 Remotion,**我們還沒查證、沒安裝**)。
- 把人從背景切出來(字躲在人後面):要人像分割模型,**沒查證任何工具。**
- 音效庫:有人推薦幾個免費音效來源,**我們沒下載、沒驗證授權。**
- 精準的停頓偵測與逐字時間碼。
- 調色的完整流程(LUT、柔膚強度、跨鏡頭一致)。

## 怎麼處理
- 遇到這些,AI 要**誠實說「這個沒驗證過 / 做不到」**,不要假裝可以。
- 驗證完的,請把結果寫進 `進度.md`,並更新 `docs/04_踩過的坑與限制.md`。
