# 字型清單與下載來源

**不附字型檔。** 只附「我們當時從哪裡下載、下載的檔案多大、SHA-256 是多少」,**要不要下載、下載哪幾款,由你(和你的 AI)自己決定。**
字型有授權,下載檔案本身也要走資安流程(見 `AGENTS.md` 硬規則 3):先看官方頁面、授權,再下載到空資料夾、核對、掃描,最後才放進專案。

## 怎麼用字型(不用安裝到系統)

- 把字型檔放進專案的 `fonts/`,**不安裝到 macOS 字型簿**。
- ffmpeg 的 `drawtext` 用 `fontfile=字型檔路徑`;做字卡圖片時,由程式直接讀字型檔。
- 每個字型下載後,在 `fonts/` 留一個說明檔:**來源網址、下載日期、大小、SHA-256、授權、怎麼移除。**
- **下載前先確認字型有你要用的字**:把全部字幕、標題的字餵給程式檢查字形;缺字(尤其是簡體字形的字型)就換。
- **有些字型檔 ffmpeg 的 `drawtext` 讀不了。** 我們遇過辰宇落雁連英數字都失敗,改成用程式把字畫成透明 PNG 再疊上去才解決。你的版本可能不同,先小測試。

## 選字型的做法(比字型本身更值得學)

1. **先找參照,不要只靠形容詞。** 我們選說話字幕的字型時,是使用者**截了一張原片的字**,我們把 4–8 款字型用**同一句話、同一個版型**並排,再比哪個最像,而不是描述「圓一點」。
2. **簡體字形問題:** 很多免費手寫/毛筆字型是簡體字形,排繁體字會缺字或被系統換字。選之前用你的實際文案測。
3. **一次只改一個變數:** 字型、粗細、顏色、光暈分開比,不要同時全換。
4. **沒有粗體版的字型:** 可以用同色描邊模擬加粗(我們試過 3 級),但小筆畫會糊在一起,太粗不好看。
5. **細字體在亮背景上可能看不清:** 看成品再決定要不要加描邊。
6. **定案後寫進風格檔:** 字型名、檔名、用在哪裡。

## 我們的選擇(僅供參考,你的不一定一樣)

- 封面首圖標題:辰宇落雁(細)——因為原片首圖是細筆手寫。
- 說話字幕:粉圓體——因為要「圓潤、粗細一致」。清松 4 也很接近,但被使用者換掉。
- 字幕與旁白:辰宇落雁 / 霞鶩文楷 / 思源宋體是常被比較的幾款。
