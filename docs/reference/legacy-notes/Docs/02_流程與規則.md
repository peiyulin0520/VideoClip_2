# 流程與規則

(改寫自幾個公開的剪片教學貼文與我們自己做過的專案,**沒有複製原文**。)

## 一、核心想法

AI 不是一次剪完整支,而是:**先講它打算怎麼剪 → 你確認 → 才動手 → 局部修 → 把你的偏好記下來。**

## 二、每支片都照這個走

1. **先給選段表,你說「可以」才剪。** 選段表每列:來源檔、起訖秒、畫面內容(一句話,只寫看得到的)、留/刪、理由。不對就在這一步改,不要等整支剪完。
2. **先給定格或一小段預覽,再輸出整支。** 試風格時先出幾格截圖(章節卡、字卡、轉場中間那一格)。
3. **局部修改要指定範圍:**「第 __ 秒到第 __ 秒換掉,其他不要動」。你說哪段就只改哪段。
4. **你的每個修正都寫進 `進度.md` 或風格檔**,下次直接照做。
5. **匯出前自我檢查**(第五節),通過才給你。

## 三、選段規則

- **同一個畫面或動作拍了好幾次:只留最好的一次**,不要重複出現。
- **不用同一段素材的重疊區間**;輸出前用程式比對起訖秒。
- 刪:黑畫面、遮鏡頭(手指、手套、機器)、模糊、重複、沒有主角入鏡、不相干的路人臉。
- **長鏡頭要分段標記**:A(主力)/ B(次選)/ C(不用),不是整支一個等級。要逐格看過,不要只做等距取樣。
- 口播影片:同一句講好幾次,留最後一次(或最順的一次);**列給使用者選,不要全自動刪**。

## 四、節奏與字卡規則

- **開頭 3 秒**要有看得出主題的畫面,關聲音也看得懂。
- **停頓**:重要時刻前留一拍,不要全部切得很緊。
- **結尾多停 1 秒**,不要硬切也不要接黑畫面。
- **字卡**:一張 ≤10 個字(重點詞 4–7 字最好),每張至少 0.5 秒;放上方或下方**避開臉**,也避開平台按鈕區(直式畫面底部約 250px、右側約 150px 不放重點)。
- **數字單獨成一張字卡**。
- **每 2–3 個鏡頭最多 1 張字卡**,開頭第一個鏡頭要有。
- 字卡內容只寫看得出來的事,不編故事。
- 停留時間:少字約 2 秒;資訊量大的約 5–6 秒。
- 兩個很滿的畫面不要交叉淡化,先收掉舊的再出新的。
- 一個畫面只放一個重點;畫面已有大字,底部字幕拿掉重複的。
- 音效**最後才上**(畫面全部定案後),不然每改一次畫面音效都要重對。

## 五、匯出前檢查(5 項)

1. 前 3 秒:關聲音只看畫面和字卡,會不會想繼續看。
2. 重複:有沒有同一畫面出現兩次(程式比對起訖秒)。
3. 字卡:每張看得完、沒擋臉、沒壓到平台按鈕區。
4. 節奏:有沒有明顯拖或趕的地方(**AI 看不到動作節奏,請你看一次**並指出)。
5. 結尾:最後有沒有多停 1 秒。

## 六、你可以直接說的修改用語

| 你說 | AI 做 |
|---|---|
| 太趕 | 每段多留約 0.2–0.5 秒,重要時刻前再多一點 |
| 太拖 | 鏡頭縮短,超過 3 秒的非重點鏡頭砍短 |
| 第 X 到 Y 秒換掉 | 只換那段,其他不動 |
| 字卡太多 | 只留重點,最多每 2–3 個鏡頭 1 張 |
| 開頭太慢 | 直接從最好看的畫面開始 |
| 記住這個 | 寫進進度.md / 風格檔 |

## 七、回饋的格式

「**第幾秒 + 哪裡不對 + (參考圖)**」。**一次把要改的地方講完**再重新輸出(每改一次都要重算,很耗時間)。

## 八、風格怎麼定

- 風格用**一句話 + 色票**定義。
- 不確定就**做三個讓你挑**(A/B/C),不要只用文字形容。
- 定案後整理成 `風格/<名稱>.md`,下次直接照做(範本:`templates/風格檔範本.md`)。

## 九、輸出規格

直式 1080×1920、30fps mp4;橫式 1920×1080;方形 1080×1080。寬高用偶數。
