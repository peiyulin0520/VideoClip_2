# 特效與字卡做法集

分兩部分:**A. 用 ffmpeg 內建濾鏡就能做的特效**(指令範例),**B. 字卡與面板的種類**(用圖片疊上去)。
**驗證狀態先講清楚:** A 部分的指令是我們在 **Windows + ffmpeg n9.0** 上實際輸出過短片的;**只有幾款我們逐格看過畫面**,其他是確認有輸出、沒有報錯。在 Mac 或不同版本的 ffmpeg 上請先小測試。

## A. ffmpeg 內建特效(可以直接叫 AI 做)

`W`、`H` 換成你的輸出尺寸。字型檔路徑在 Mac 和 Windows 不同,請 AI 查實際路徑。

| 特效 | 做法(ffmpeg 濾鏡) | 備註 |
|---|---|---|
| 顆粒(底片感) | `noise=alls=24:allf=t+u` | 數值越大越粗 |
| 暗角 | `vignette=angle=PI/3.2` | |
| 柔焦光暈 | `[0]split[a][b];[b]gblur=sigma=16[bb];[a][bb]blend=all_mode=screen:all_opacity=0.55` | 高光處會暈開 |
| 手震 | `crop=iw-44:ih-44:x='22+16*sin(t*30)':y='22+16*cos(t*37)',scale=W:H` | 先裁小一圈,再用正弦移動 |
| 色差故障 | `rgbashift=rh=-9:bh=9:enable='lt(mod(t,1),0.25)'` | 每秒前 0.25 秒閃一下 |
| 慢慢放大(照片) | `zoompan=z='min(zoom+0.002,1.3)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=72:s=WxH:fps=24` | 一次只能處理影格數有限 |
| 閃白 | `fade=t=in:st=0:d=0.7:color=white` | |
| 橫式變直式(模糊填滿) | `[0]split[a][b];[b]scale=W:H:force_original_aspect_ratio=increase,crop=W:H,gblur=sigma=30[bg];[a]scale=W:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2` | 背景是自己放大模糊的畫面 |
| 殘影拖尾 | `drawtext=…,lagfun=decay=0.96` | 文字加上拖影 |
| 打字機 | 多個 `drawtext`,各用 `enable='gte(t,秒數)'` 逐字顯示 | 要逐字準備文字檔 |

### 轉場(`xfade`)

寫法:`[0][1]xfade=transition=名稱:duration=0.9:offset=1.0`(兩段影片的尺寸、影格率要一致;`offset` 是第一段開始轉場的秒數)。

我們輸出過預覽的名稱:`fade`(交叉淡化)、`fadeblack`(淡到黑)、`fadewhite`(淡到白)、`dissolve`(顆粒溶解)、`wipeleft`(左擦除)、`slideleft`(左滑)、`smoothleft`(柔順左移)、`circleopen`(圓形展開)、`circleclose`(圓形收合)、`radial`(放射掃過)、`pixelize`(像素化)、`zoomin`(放大轉入)、`horzopen`(水平開門)、`vertopen`(垂直開門)。

**重要:** 兩個很滿的畫面不要交叉淡化,先收掉舊的再出新的。

### 我們的限制(誠實說)

- **做不到或做得很勉強:** 彈出縮放(用時間運算的縮放沒有正確運作)、逐字跳出的動畫、字卡彈跳。這些要逐格輸出,或用別的工具(例如專門用程式做影片動畫的專案;**我們還沒查證、沒安裝**)。
- 把人從背景切出來(字躲到人後面):**沒有工具,沒做。**
- 預覽網頁上的特效,有些是網頁畫的示意,**不代表 ffmpeg 輸出一樣。**

## B. 字卡與面板的種類(疊圖做法)

做法通則:**字卡先畫成透明背景的 PNG**(整個畫面大小,字和底在正確的位置),再用 ffmpeg 的 `overlay` 疊上去,加上淡入淡出。

| 種類 | 長相 | 備註 |
|---|---|---|
| 章節卡 | 小字序號(CHAPTER 01)+ 超大襯線標題 + 一條細線 + 副標,放左上,出現約 2 秒 | 最常用 |
| 步驟頁籤 | 上方一排「01 籌備 \| 02 布置…」,目前章節用重點色 | 可以只在章節開頭出現一下 |
| 問題膠囊 | 上方深色半透明圓角膠囊,左邊小圓標「Q1」,右邊是問句 | 回答期間留著 |
| 對話框 | 深色半透明圓角框 + 重點色引號,貼近說話的人,**不要有尖角尾巴(會壓到臉)** | |
| 打勾清單卡 | 圓角卡內列幾個 ✓ 項目 | |
| 聚光燈 | 背景變暗,主角用圓形露出,外圈一條細線 | 位置要逐鏡頭手調 |
| 毛玻璃面板 | 半透明 + 模糊的圓角面板,放圖表或資訊 | 模糊要用 `boxblur` 另做 |
| 拍立得相片牆 | 幾張白框相片傾斜疊在角落,用影片自己的畫面 | |
| 關鍵詞色塊 | 字幕裡重點詞底下加色塊(橘、紅、螢光綠) | 先問你要幾種顏色 |
| 取景框角標 | 畫面四角的細線 L 形 | 增加電影感 |
| 圓角預覽小卡 | 底部圓角小卡,左上角 n/N 計數,放示範畫面 | 要用圓角遮罩 |

## C. 說話字幕(配人聲通用)的做法

這是一種常見的做法:**說話的字**:圓潤手寫、帶一點發光、左右各一道斜線 `\ … /`、整串字歪 5–12 度,放在說話的人的嘴或臉附近;**旁白**:沒有斜線,用乾淨的白字。

- 每一句各自做一張全畫面的透明 PNG(字、斜線、光暈、旋轉都畫好),用 `overlay` 疊上去,淡入淡出。
- 需要先知道**每一句的內容和出現時間**:語音轉文字(見 `docs/04`)只是草稿,要人工校對。
- 逐字彈出、字隨節奏跳動:**做不到**,我們沒有解決。
