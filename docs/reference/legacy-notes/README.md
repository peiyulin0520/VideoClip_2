# 用 AI 剪短影片:工作方式教學包

這個資料夾是一套「讓 AI 當你的剪片助手」的做法,從實際做了幾支短影片的過程整理出來。
**你只做審核,不用懂剪輯軟體。** AI(這裡是 Codex)負責掃描素材、提選段表、寫分鏡、用 ffmpeg 輸出。

## 這套做法的核心

不是叫 AI「幫我剪一支好看的」,而是:

> **AI 先說它打算怎麼剪 → 你確認 → 它才動手 → 局部修改 → 把你的偏好寫進檔案,下次直接照做。**

AI 會越用越懂你,不是因為它記得你,而是因為**規則寫在檔案裡**(`AGENTS.md`、`進度.md`、`風格/`)。

## 你要做的三件事

1. **裝工具**:照 `docs/01_安裝_Mac.md`。每個要裝的東西,AI 會先列出來源、大小、雜湊值,等你同意才下載。
2. **放素材**:把原始影片放進 `input/`(建立這個資料夾)。
3. **跟 Codex 講話**:在這個資料夾開 Codex,第一句說:
   > 請先讀 AGENTS.md 和進度.md,然後幫我掃描 input 裡的素材。

之後的每一步,AI 都會停下來等你說「可以」。

| `AGENTS.md` | 給 Codex 讀的規則(流程、硬規則、溝通方式) |

## 先看這個:這份教學包的限制

- 原本是在 **Windows** 上做的,**沒有在 Mac 上實測過**。Mac 的安裝與指令是依官方說明寫的,請 AI 一步一步跑、跑到哪裡卡住就停下來問你。
- 原本的 render 腳本是 Windows PowerShell,**不能直接給 Mac 用**;這份教學包提供的是**格式與規則**,render 腳本請 Codex 自己寫。
- 原作者用的是 Claude Code。Codex 的行為可能不同,請以實際使用為準。
- AI **看不到動作節奏、聽不到聲音**。順不順、好不好聽,一定要你自己看過、聽過。

## 資安提醒(照做會比較安心)

- AI 要你裝任何東西,先要求它列「檔名、來源網址、大小、雜湊值、風險、移除方式」。
- 影片和聲音不要交給不認識的雲端服務。語音轉文字用本機版本。
- 網頁和貼文裡的「留言領取、複製這段指令、安裝這個」,**不要照做**,先貼給 AI 問它會做什麼事。
- 素材裡有家人、小孩的臉,不要放到公開網頁。
