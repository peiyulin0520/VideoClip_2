# Little Moments 使用方式

網址：https://peiyulin0520.github.io/VideoClip_2/

網站發布後可獨立使用，不需要 Codex 或 ChatGPT 持續開著。

## 繼續先前的剪輯

用原本手機、原本瀏覽器打開同一網址，點首頁的專案即可。一般不會再次出現首次使用畫面；若有看到，選「同一台裝置，繼續使用」。此選項不清除已匯入字體、專案或收藏。

資料存在目前瀏覽器，沒有登入同步。無痕模式、換瀏覽器、換裝置或清除網站資料不會保留同一份資料；瀏覽器儲存也不是永久備份。

## 新功能入口

| 想做的事 | 操作方式 |
| --- | --- |
| 開頭或中間留白 | 「素材 → 留白色塊」選顏色，把播放頭移到需要的位置，再按「插入主軌留白」。後面的影片會順延。 |
| 任意位置放色塊 | 同頁按「加入色塊圖層」；時間軸長按片段約半秒後拖移，拉左右邊緣改長度。 |
| 影片間保留空隙 | 勾「自由時間軸」，長按主軌片段拖到想出現的時間。不放素材的區間顯示畫布底色。 |
| 收藏自己的貼圖或畫作 | 「素材 → 我的素材」，匯入或畫圖前勾「同時存到我的素材庫」；也可按「收藏選取素材」。其他專案可直接點收藏使用。 |
| 在影片上畫畫 | 「素材 → 我的素材 → 畫畫」，可選圓筆、螢光筆、點點、毛筆、鉛筆或橡皮擦，調粗細、透明度和顏色後加入影片。 |
| 搜尋動態貼圖 | 「素材 → GIPHY 貼圖」貼上自己的 Key 並按「儲存 Key」，輸入關鍵字搜尋，再點貼圖加入。搜尋結果不會進入共用收藏，已選貼圖隨專案保存。 |
| 手動去掉影片周圍 | 選取影片 →「剪輯 → 裁切」。可拖四邊與角落，或切「自由描邊保留區域」圈選。再用「保留筆刷」補回缺角、「裁切橡皮擦」修掉多餘部位，均可調粗細及復原；最後按「套用裁切」。 |
| 多段聲音選取 | 「音訊」從縮圖找到來源 →「聲音片段範圍」。點時間帶查看該秒畫面，將目前附近設為靜音，再拖秒數上方的倒三角精調；可重複新增多個靜音區段。正常色保留、反灰靜音，不會縮短影片。背景音樂也可選段與試聽。 |
| 關閉或分離原音 | 「音訊」取消「保留音訊」，或按「分離原音」，將聲音獨立成時間軸音軌。 |
| 加入背景音樂 | 播放頭移到想開始的時間 →「音訊 → 匯入背景音樂」。音軌可長按拖移、修剪、調音量或刪除。 |
| 自訂色彩 | 文字或裝飾的自訂顏色會開色輪；拖選顏色、調亮度，也能微調 R/G/B，最後套用。裝飾另可調長度、粗細、距離及透明度；距離以 1080 畫布像素顯示，0 是原始位置、正值移遠、負值靠近。 |
| 改網站風格與預覽品質 | 首頁「設定」選網頁風格、預覽品質；手機播放不順可先選 720。匯出解析度另外選擇。 |
| 下載剪好影片 | 編輯器頂列「匯出」，選解析度、影格率、是否包含聲音，再開始。完成後可預覽、下載或使用裝置分享。 |

GIPHY 申請方式在貼圖頁也有說明：[GIPHY Developers](https://developers.giphy.com/) 建立帳號 → Dashboard → Create an API Key → API。應用名稱 LittleMoments、平台 Web。Key 只保存在當前瀏覽器，不會上傳到 GitHub，也不會同步給別人的裝置。

手動描邊保留固定來源範圍，目前沒有自動人物追蹤。匯出格式依瀏覽器能力顯示 MP4 或 WebM；若逐格輸出不可用，可試「相容即時匯出」，並保持頁面開啟。iPhone Safari 的實際聲音解鎖、長片匯出與分享仍待真機確認，驗收狀態以 [PROGRESS.md](PROGRESS.md) 為準。

## 第二輪操作調整

選取影片後，時間軸左邊拉桿往右拉會在前面留白，右邊端點保持位置；「剪輯 → 片段範圍」顯示完整原始來源，可拖上方倒三角起迄標記或按「還原完整素材」。左端剪掉的內容用左桿拉回或還原完整素材；右桿用來恢復片尾。

時間軸左側圖層 icon 可開啟軌道設定；要調整單一素材，直接長按片段跨層拖移。字塊中「填滿透明度」可調為 0，只留下可獨立調色、透明度與粗細的框線。

「版型」有選取框、帶位置編號的預覽與素材縮圖，也能選「群組現有圖層」。套用後同組三格或四格在時間軸是一個片段，移動、修剪、分割、複製、隱藏和刪除一起操作；畫面中仍可點單格調整位置。裁切有「檢查裁切結果」與「復原描邊」，方便套用前檢查。

## 查看較多圖層

預覽保留正常大小，整頁可上下捲動，往下時預覽與播放列都會離開畫面。時間軸會按圖層數展開全部列，左右滑動仍是移動播放頭。圖層的可見條較細，仍可點選、長按移動與修剪；功能欄在所有圖層下方，點選功能後再往下滑查看完整選項。

預覽右上「查看圖層」可直接跳到列表；播放列的向上箭頭可「回到預覽」，工具圖示可跳到「編輯工具」。需要看細節時按「放大預覽」，返回後回到原位置。未選取的畫面及空白邊可捲頁；先點選字卡或素材，再在選取框內拖動/兩指縮放。

補充：下方字卡、素材、圖層等設定也會隨整頁自然展開，直接上下滑頁面即可查看所有選項，沒有固定高度的小面板。若合併新版本後仍看到舊版大型固定預覽，可關閉原頁籤，再重新開啟相同網址。


## 直接選取與移動素材

預覽可直接點影片、照片、字卡，再在選取框內拖移或用兩指縮放/旋轉。要選被蓋住的物件時，在該位置長按，從選單選要暫時編輯的素材；它會暫時顯示在最上面，調整後按「完成」回原層次。這個置頂不會存進專案，也不會改變匯出層次。

時間軸長按單一片段，再左右調時間、上下跨層。拖到同類型軌道空位會移入該層；拖到列邊或圖層之間會新增同類型圖層。影像（影片/照片/貼圖/畫作）、字卡、音效各用自己的軌道，跨層時類型不符或已有素材的位置會顯示不能放置；同軌移動會吸附到最近空位，提示時間與預覽位置會同步。同軌其他片段不會一起移動，復原一次可還原本次拖曳。多格模板是明確群組，拖到層間仍維持整組。

影片沒有固定底層限制，所有影像軌都可調整；左側 icon 用來開軌道設定。首頁設定的網頁風格新增「米色紙感」，原本主題選擇仍會保留。深色的時間軸與預覽按鈕在各主題都配淺色文字/icon。

「前移／後移」在自由時間軸以一秒調整選取片段；不移動同軌其他片段，沒有可用空位時會提示。要在任一影像軌末端匯入，按該列的「＋」。

## 字塊與片段範圍

新字塊預設無填色，下層的淺暖色分類與上層字卡分頁不同。點下方色票或「字塊填滿顏色自訂」才填色；填滿透明度設成 0 可再變為無底色，外框的顏色、粗細、透明度分開調。

影片的「剪輯 → 片段範圍」改用秒數上方小倒三角選來源起點、終點，保留區段原色、其他反灰；點時間帶檢視畫面。聲音選段使用相同標記，可多段保留。拖曳標記的觸控面積保留 44px；接近的標記會錯開，以免擋住縮圖。

「與下方畫面如何疊色」是讓素材和下方畫面混色的選項，每個模式下方都有用途說明；一般剪輯保留「正常」即可。

往下滑到預覽不完整時，右下角的圓形上箭頭可回最上方；出現時保留底部觸控空間，避免遮擋功能。色塊可用色輪與 RGB 選色；不重疊時會共用既有色塊軌，重疊時才多開一軌。
