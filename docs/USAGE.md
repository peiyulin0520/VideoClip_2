# Little Moments 使用方式

網址：https://peiyulin0520.github.io/VideoClip_2/

網站發布後可獨立使用，不需要 Codex 或 ChatGPT 持續開著。

## 繼續先前的剪輯

用原本手機、原本瀏覽器打開同一網址，點首頁的專案即可。一般不會再次出現首次使用畫面；若有看到，選「同一台裝置，繼續使用」。此選項不清除已匯入字體、專案或收藏。

資料存在目前瀏覽器，沒有登入同步。無痕模式、換瀏覽器、換裝置或清除網站資料不會保留同一份資料；瀏覽器儲存也不是永久備份。

## 新功能入口

| 想做的事 | 操作方式 |
| --- | --- |
| 開頭或中間留白 | 「素材 → 留白色塊」選顏色，把播放頭移到需要的位置，再按「插入主軌留白」。後面的影片會順延。 |
| 任意位置放色塊 | 同頁按「加入色塊圖層」；時間軸長按片段約半秒後拖移，拉左右邊緣改長度。 |
| 影片間保留空隙 | 勾「自由時間軸」，長按主軌片段拖到想出現的時間。不放素材的區間顯示畫布底色。 |
| 收藏自己的貼圖或畫作 | 「素材 → 我的素材」，匯入或畫圖前勾「同時存到我的素材庫」；也可按「收藏選取素材」。其他專案可直接點收藏使用。 |
| 在影片上畫畫 | 「素材 → 我的素材 → 畫畫」，可選圓筆、螢光筆、點點、毛筆、鉛筆或橡皮擦，調粗細、透明度和顏色後加入影片。 |
| 搜尋動態貼圖 | 「素材 → GIPHY 貼圖」貼上自己的 Key 並按「儲存 Key」，輸入關鍵字搜尋，再點貼圖加入。搜尋結果不會進入共用收藏，已選貼圖隨專案保存。 |
| 手動去掉影片周圍 | 選取影片 →「剪輯 → 裁切」。可拖四邊與角落，或切「自由描邊保留區域」圈選。再用「保留筆刷」補回缺角、「裁切橡皮擦」修掉多餘部位，均可調粗細及復原；最後按「套用裁切」。 |
| 多段聲音選取 | 「音訊」從縮圖找到來源 →「聲音片段範圍」。點時間帶查看該秒畫面，將目前附近設為靜音，再拖秒數上方的倒三角精調；可重複新增多個靜音區段。正常色保留、反灰靜音，不會縮短影片。背景音樂也可選段與試聽。 |
| 關閉或分離原音 | 「音訊」取消「保留音訊」，或按「分離原音」，將聲音獨立成時間軸音軌。 |
| 加入背景音樂 | 播放頭移到想開始的時間 →「音訊 → 匯入背景音樂」。音軌可長按拖移、修剪、調音量或刪除。 |
| 自訂色彩 | 文字或裝飾的自訂顏色會開色輪；拖選顏色、調亮度，也能微調 R/G/B，最後套用。裝飾另可調長度、粗細、距離及透明度；距離以 1080 畫布像素顯示，0 是原始位置、正值移遠、負值靠近。 |
| 改網站風格與預覽品質 | 首頁「設定」選網頁風格、預覽品質；手機預設使用540輕量預覽，標準為720。匯出解析度另外選擇。 |
| 下載剪好影片 | 編輯器頂列「匯出」，選解析度、影格率、是否包含聲音，再開始。完成後可預覽、下載或使用裝置分享。 |

GIPHY 申請方式在貼圖頁也有說明：[GIPHY Developers](https://developers.giphy.com/) 建立帳號 → Dashboard → Create an API Key → API。應用名稱 LittleMoments、平台 Web。Key 只保存在當前瀏覽器，不會上傳到 GitHub，也不會同步給別人的裝置。

手動描邊保留固定來源範圍，目前沒有自動人物追蹤。匯出格式依瀏覽器能力顯示 MP4 或 WebM；若逐格輸出不可用，可試「相容即時匯出」，並保持頁面開啟。iPhone Safari 的實際聲音解鎖、長片匯出與分享仍待真機確認，驗收狀態以 [PROGRESS.md](PROGRESS.md) 為準。

## 第二輪操作調整

選取影片後，時間軸左邊拉桿往右拉會在前面留白，右邊端點保持位置；「剪輯 → 片段範圍」顯示完整原始來源，可拖上方倒三角起迄標記或按「還原完整素材」。左端剪掉的內容用左桿拉回或還原完整素材；右桿用來恢復片尾。

時間軸左側圖層 icon 可開啟軌道設定；要調整單一素材，直接長按片段跨層拖移。字塊中「填滿透明度」可調為 0，只留下可獨立調色、透明度與粗細的框線。

「版型」有選取框、帶位置編號的預覽與素材縮圖，也能選「群組現有圖層」。套用後同組三格或四格在時間軸是一個片段，移動、修剪、分割、複製、隱藏和刪除一起操作；畫面中仍可點單格調整位置。裁切有「檢查裁切結果」與「復原描邊」，方便套用前檢查。

## 查看較多圖層

預覽保留正常大小，整頁可上下捲動，往下時預覽與播放列都會離開畫面。時間軸會按圖層數展開全部列，左右滑動仍是移動播放頭。圖層的可見條較細，仍可點選、長按移動與修剪；功能欄在所有圖層下方，點選功能後再往下滑查看完整選項。

預覽右上「查看圖層」可直接跳到列表；播放列的向上箭頭可「回到預覽」，工具圖示可跳到「編輯工具」。需要看細節時按「放大預覽」，返回後回到原位置。未選取的畫面及空白邊可捲頁；先點選字卡或素材，再在選取框內拖動/兩指縮放。

補充：下方字卡、素材、圖層等設定也會隨整頁自然展開，直接上下滑頁面即可查看所有選項，沒有固定高度的小面板。若合併新版本後仍看到舊版大型固定預覽，可關閉原頁籤，再重新開啟相同網址。


## 直接選取與移動素材

預覽可直接點影片、照片、字卡，再在選取框內拖移或用兩指縮放/旋轉。要選被蓋住的物件時，在該位置長按，從選單選要暫時編輯的素材；它會暫時顯示在最上面，調整後按「完成」回原層次。這個置頂不會存進專案，也不會改變匯出層次。

時間軸長按單一片段，再左右調時間、上下跨層。拖到同類型軌道空位會移入該層；拖到列邊或圖層之間會新增同類型圖層。影像（影片/照片/貼圖/畫作）、字卡、音效各用自己的軌道，跨層時類型不符或已有素材的位置會顯示不能放置；同軌移動會吸附到最近空位，提示時間與預覽位置會同步。同軌其他片段不會一起移動，復原一次可還原本次拖曳。多格模板是明確群組，拖到層間仍維持整組。

影片沒有固定底層限制，所有影像軌都可調整；左側 icon 用來開軌道設定。首頁設定的網頁風格新增「米色紙感」，原本主題選擇仍會保留。深色的時間軸與預覽按鈕在各主題都配淺色文字/icon。

「前移／後移」在自由時間軸以一秒調整選取片段；不移動同軌其他片段，沒有可用空位時會提示。要在任一影像軌末端匯入，按該列的「＋」。

## 字塊與片段範圍

新字塊預設無填色，下層的淺暖色分類與上層字卡分頁不同。點下方色票或「字塊填滿顏色自訂」才填色；填滿透明度設成 0 可再變為無底色，外框的顏色、粗細、透明度分開調。

影片的「剪輯 → 片段範圍」改用秒數上方小倒三角選來源起點、終點，保留區段原色、其他反灰；點時間帶檢視畫面。聲音選段使用相同標記，可多段保留。拖曳標記的觸控面積保留 44px；接近的標記會錯開，以免擋住縮圖。

「與下方畫面如何疊色」是讓素材和下方畫面混色的選項，每個模式下方都有用途說明；一般剪輯保留「正常」即可。

往下滑到預覽不完整時，右下角的圓形上箭頭可回最上方；接近頁尾時會收起浮鈕，避免遮擋最後工具；頁尾不另外保留空白。色塊可用色輪與 RGB 選色；不重疊時會共用既有色塊軌，重疊時才多開一軌。


## 收合時間軸與整組模板

時間軸預設先收合；點「展開時間軸」才顯示全部圖層，再點可收合。同一專案在此頁籤會記住你自行展開的選擇，預覽的「查看圖層」也會先展開。

在「版型」選膠卷/拍貼/相紙，選每格素材並套用後，在預覽點任一格，拖動或兩指縮放都只調整整組，內部影片與框架一起變。要選個別影片片段，可點該格再到「剪輯 → 片段範圍」，或在「版型 → 每格來源與補時」展開該格，拖來源起迄標記；也能放大選段。

「每格共同長度」決定整組秒數；來源短於此長度會自動補黑/白。每格可延後出現、選補黑/補白，將播放頭移到要空白的位置，按「在此格目前秒數插入色塊」，再拖下方標記改長度。色塊期間暫停來源與聲音，之後接續，不會凍結最後一幀。重新套用匹配的素材時保留已選片段、色塊與整組位置。

## 精確標記多組靜音

「音訊 → 聲音片段範圍」點時間帶查看畫面，定位後按「標記靜音起點」；再定位終點，按「標記靜音終點並新增」。可重複多組，並切「調整靜音標記」拖各組倒三角。灰色是靜音，正常顏色保留；移除一組只恢復該段聲音。原快速半秒靜音也保留。

## 故事與特效

「版型 → 展開故事」選二或三格並套用：先單片上下展開，再依序加入其他格，中央 NOVEMBER 快速切換字體，結尾暖光。下方可改中央文字、三種字體、切換間隔、展開/進入時間與閃光開關，來源與補時和其他模板相同。

「特效」可加入閃光、暖光掃過、經黑或經白。先把播放頭移到剪接處再加入，調出現時間、長度與強度；「檢視特效中點」看最亮/暗的位置，對準交接處即可。特效可獨立移除，與聲音/影片設定分開保存，匯出會包含。


## 多組片段與局部復原

在「剪輯 → 片段範圍」縮小第一組後，點縮圖把白線移到未選秒數，按「在白線位置新增一組起迄標記」建立第二組；再拖上方小倒三角調起迄，可繼續新增。點時間本身只定位，不會自動生成。原色保留、灰色不選；影像與該段原音一起留空白，原時間位置不接短。可移除個別組，原始素材仍保留，隨時拖回範圍。

視窗右上「復原上一步選段」只復原這次視窗的調整，底部「取消」放棄全部草稿，「套用」才寫入專案。「音訊 → 聲音片段範圍」也能新增多組保留聲音；只改聲音，不改影片畫面，另保留多組靜音起點/終點操作。

## 命名、圖層分類與多選

選素材後到「剪輯 → 命名」，名稱會顯示在時間軸。展開時間軸後，各類型標題可分別收合影像、文字、貼紙、音訊，摘要保留秒數位置；不改實際上下順序。

長按左側 icon 進多選，再點其他 icon 勾選。上方操作列可批次上移/下移、隱藏/顯示、刪除、合併與完成。只有同類素材可合併；不重疊時「合併成同一列」保留原秒數，重疊時可明確選「合併並依序接續」。鎖定的圖層先解鎖，多格模板保持整組。全域「復原」可還原已套用的批次操作。

## 菱形關鍵幀

選預覽或時間軸上的素材，把白線移到起點，點復原左側的菱形，記錄第一點。關閉視窗，移白線到後面的秒數，再點菱形並調位置、大小、旋轉、透明度、亮度、飽和度、色溫或色彩；之後改位置或雙指縮放也會記到當下。兩個菱形之間線性漸變，最後一點之後保持設定。

時間軸上的菱形及視窗中的秒數按鈕可定位；每點可移除。膠卷/多格版型的菱形作用整組，框架與各影片同步。分割保留當下曲線；「位置、大小、旋轉歸位」也寫在目前時間點，可全域復原。

## A/B 轉場與影片特效

「特效」有「轉場」與「影片特效」及分類。選項的 A/B 動畫顯示實際效果；25 種 A/B 轉場要先在同一影像列準備兩段相接素材，再選 A → B 交接。可調長度、檢視交接與移除；原閃光/暖光/經黑/經白也可在白線附近加入。

影片特效包含震動、節奏縮放、柔焦、黑白/暖/冷、顆粒、故障/色散、暗角、飄雪/星光。先移白線再加入，在「已使用的特效」按「調整特效起迄」設定秒數，強度另在「調整影片特效」中設定；移除不刪素材。動畫選項使用自製 A/B 圖像，和預覽/匯出共用效果流程。

## GIPHY 與主題圓圈

Key 儲存後素材頁只顯示搜尋及貼圖，透明區直接透出主題底色。變更/移除 Key 到首頁「設定 → GIPHY 貼圖」，只保存在這台裝置；不會寫入專案或上傳影片。未設定時素材頁也可初次輸入。

首頁「設定 → 網頁風格」直接點底色與文字顏色的圓圈，外圈表示目前主題；不再使用下拉選單。

## 試播、直接定格與交接效果（PR #8）

音訊選段視窗左側小畫面、右側時間軸；試播時白線會隨聲音移動，按暫停後再標記。可在起點按「標記靜音起點」、移到終點按新增；或在白線處新增保留聲音的起迄。調整標記/移除各段或右上復原即可，不再提供固定 0.25 秒靜音與還原完整聲音捷徑。

「定格」在預覽下方的播放工具列。選中影像/文字/貼紙或整組模板，按一下記錄當前素材及秒數，按鈕會亮色。移動白線後直接拖預覽、雙指縮放會記錄下一點，兩點間漸變；不是把影片內容停止。需要數值時再到「圖層 → 定格細部調整」，可定位/移除菱形、改位置/大小/亮度/色彩。其他圖層屬性仍在原頁籤。播放或兩片交接時不顯示編輯白框。

兩片影像同列相接處的小圓底＋會開特效頁並選好 A/B。「已使用的特效」在動畫選項之前，名稱可點選定位，旁邊可移除。每種轉場在同一交接只加入一次，選項亮框顯示已選；不同種類可混搭，換另一交接可再用相同種類。舊專案完全重複的交接效果會整理為一個，保留第一個設定。

畫畫的鉛筆可見石墨線與顆粒；感壓筆在支援變動壓力的裝置上依壓力變粗細，一般手指或滑鼠則依快慢與頭尾收筆變化。可復原上一筆、調粗細與顏色後儲存 PNG。

主類與次類用不同背景/選取線區分，新增文字使用強調色。GIPHY 結果只呈現貼圖，上方仍保留整體來源標示；Key 設定方式與資料僅存在裝置的行為相同。

## 分類優先與緊湊操作（PR #9）

展開整個時間軸先看到影像、文字、貼紙及音訊的分類摘要；點類別左側箭頭才顯示該類素材。收合整軸再開回到分類摘要。新增或明確選取素材時，只會打開該類供當下編輯，不改原圖層順序。

下方功能、選項與 popup 共用 14px，備註更小；特效是三欄小動畫加名稱，已選框線及已用清單保留。播放列圖示下有預覽/工具/縮小/放大短標籤。影像交接的＋縮成列間小圓圈，沒有額外整列空位，點它仍直接開正確的 A/B 特效。

版型示意圖在左，每格的素材選單在右，依第 N 格與位置名稱選擇，無須和預覽格位排在同一高度；下方不再重複列選單。每格來源的細部片段調整仍保留。

畫畫保留一個感壓筆；鉛筆以紙紋顆粒及透明空隙呈現素描感，可重複描畫加深。選中手繪後，可直接從畫布透明區單指拖移，不必先雙指縮放；普通輕點仍可選下層素材。

自由保留、擦除及描邊時，按住下方控制圈操控上方瞄準圈，手指不擋住目標。預設偏移 56px，可調 0–120；筆刷粗細控制上方目標大小，描邊沿十字中心。逐筆復原/檢查結果/取消保持可用；只保存真正保留或擦除的位置，控制圈與連線不會出現在成品。


## 全介面字級與文字框內距

首頁、設定、頂部標題/專案名稱、播放列、時間軸、功能與選項、彈出視窗一律14px；只有說明註解使用11px。主題名稱、群組數與起迄標籤也用14px，不能把所有small標籤視為註解。按鈕/文字框左右內距6px，輸入框上下4px，選項區塊留白縮小，觸控仍44px。播放時間分兩行，在窄螢幕顯示目前與總長。

此設定只影響操作介面；影片裡文字素材的大小、字塊樣式及匯出仍依專案設定。


## 全頁可讀配色與小字字距

備份選項、字體包、下載狀態與各操作卡片的底色、主字及說明色一同跟隨主題；深色底有淺字、淺色底有深字。連結、成功/警示/刪除文字有可讀的專用配色，字體未下載時範例文字保持可讀。

操作字級維持14px，字距/詞距收為-0.02em、行高1.25；11px註解字距-0.01em、行高1.3。時間軸與播放時間使用更緊行高以配合固定小列。這些是介面設定，不改影片素材內的字距、文字框或匯出。

## 版型與單素材動畫

選版型後可改底部文字或留空、自訂底色/文字色與框架透明度；透明度只調框架。已套用版型即時更新，也可先設好再套用。進出場動畫能指定進場、出場與長度；特效頁可選「單一素材」或「兩個素材銜接」，單一素材進場以B對透明側、退場以A對透明側，版型整組一起動。A/B選單優先顯示命名片段。

每格只有一條來源軸；按進階設定才顯示延後出現、補黑/補白、色塊及放大片段範圍。插入色塊後可改起迄秒數或刪除。動態預覽的▶開始、⏸暫停，播放中按鈕變色；版型結果會預覽真正合成畫面。

回頂箭頭在最底仍可用；依瀏覽器可視高度及手機寬度調整。390px為基準，較大手機字級等比最多放大10%，窄手機保留可讀字級和44px觸控。時間軸文字仍保持比功能列小。


版型頁可直接輸入版型寬度/高度；拍貼、膠卷和故事預設長型，四格相紙方形，改右上影片比例不會拉扁版型。右上比例是最後整支影片比例；預覽有清楚輸出邊線，框外斜紋不會匯出。比例旁的畫質按鈕預設低畫質540，可切換標準/平衡/精細，保留目前秒數；選擇會記住，匯出畫質仍另選。


## 特效時長與成對起迄

「特效 → 轉場」可選單一素材或兩個素材銜接。單一素材選進場（B）或出場（A），挑效果後按「調整特效起迄」；版型頁的進出場也使用同一介面。進出場與原版型動態效果互相切換，避免疊上兩套動態。

10秒影片設定3秒特效，影片仍是10秒，這3秒內影片會繼續播放。單素材進場固定從0秒開始，只調迄或時長；退場固定在片尾結束，只調起或時長，兩個欄位會連動。畫面特效與兩片銜接可調任意起迄。兩支各10秒的影片仍是20秒，3秒轉場預設分配到A最後1.5秒及B最初1.5秒；可以各自調整A起點與B終點。

來源、聲音、畫面特效及銜接可點縮圖或拖白線定位，按「在白線位置新增一組起迄標記」就會同時建立起點與終點；單素材進出場只保留一個可動標籤。拖秒數上方的起／迄標籤調整（多組選段仍有序號），各組都能移除，右上可復原。▶播放、⏸暫停，白線隨播放移動；取消不改專案，套用才保存。影片特效、聲音範圍、來源修剪及版型來源使用相同的成對標籤。來源修剪刪到沒有選區時不能誤套回整支影片，可復原或重新新增。


## 特效代表字及穩定預覽（PR #10追加）

時間軸的棕色代表字在兩片銜接處，藍綠色在單素材實際特效起點；收合群組仍看得到。點代表字開對應設定，同秒有多種作用範圍時會列出供選擇。

進專案先顯示真實載入進度，完成素材讀取、輕量預覽檔及首幀準備到100%才可編輯，不會自行播放。高解析度或較難解碼的影片會在裝置本機建立預覽檔，540/720依所選品質準備；再次開啟使用快取，不更改原始檔。若瀏覽器無法建立，會提示並改用原檔。第一次準備較久，長片仍受手機解碼能力影響。

主影片播放時先停特效卡示意，避免同時合成；看示意或片段試播會先停主影片。回到背景會暫停，返回後自行按▶。分離原音、調音量、選段及匯出包含／不含聲音仍保留；匯出永遠讀原始素材，不使用低畫質預覽檔。

長片時間軸使用少量取樣縮圖鋪滿全部片長，放大後也不會因格數上限截斷後段；取樣涵蓋來源全長，後段使用後段畫面，不是逐幀產生大量圖片；縮圖顯示對應時間附近的取樣畫面，精確秒數以預覽為準。縮圖只供定位，影片播放與匯出仍依原始來源及片段設定進行。

## 主時間軸每2秒來源縮圖（PR #11）
主時間軸每2秒取該來源秒數的畫面，片段範圍popup則仍用概覽縮圖。更新後重新開啟原專案，載入會顯示「建立每2秒縮圖」；完成後保存，之後重開直接重用，不需重新匯入影片。拖移與放大只繪出可見範圍，後段仍用後段來源；修剪及變速會按來源時間對應。若個別時間點不能解碼會標示缺圖並提示，重開可再試，不會用首幀假裝補齊；影片及匯出仍使用原素材。
