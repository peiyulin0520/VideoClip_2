# iPhone 實測：修剪、貼圖播放、圖層拖曳與版型群組

依使用者第二輪實測七點修改，仍只發佈 VideoClip_2。四段錄影只在 /tmp 分析，不將第三方畫面或真人影片加入 repo；驗收用自製色片/GIF。

- 時間軸左端修剪保持片尾位置、在前面留下空白；停止對手勢結果套 relayout。來源 in/out 永遠可恢復，另提供完整來源縮圖選區與重設，避免裁過後無法辨認素材範圍。既有明確排序按鈕保留。
- 貼圖不放大上傳成整個預覽解析度；小 GIF 重用已合成的影格，預覽按固定時鐘影格編號更新，避免 RAF 取樣造成 30fps 不均；同素材不同片段分開解碼狀態，不互相覆寫。Safari 原生影片池保留極小可見度，避免 opacity:0 被系統節流。
- 時間軸左邊軌道 icon 直接上下拖曳排序，有落點線；主軌固定底層。短按保留原軌道設定，拖曳不誤開設定。
- 裁切已檢視使用者錄影，手動多邊形保留範圍與示範輪廓大致一致；尚詢問其具體不符處。先增加套用前透明結果預覽與復原描邊，仍為靜態來源座標，不假稱人物追蹤。
- 字塊填滿透明度允許 0；框線顏色、粗細、透明度獨立（舊框線未指定 opacity 預設 1）。只有框線時仍保留文字與內距。
- 版型選取明顯框選/文字回饋、縮圖顯示編號及上中下/四角位置；格子選單搭配素材縮圖、原檔名或貼圖標題，避免僅顯示 ID。
- 版型採「一個圖層含多個同時素材」，可整組拖移、修剪、隱藏/刪除，框架隨整組進出，刪組不殘留。既有每格一軌的版型載入時合併並保留媒體/裁切/音量設定。可選現有疊加圖層組成版型；套用移除原分散片段但不刪檔，可復原。

驗收：來源與時間軸雙向恢復、空白實際畫面、同 GIF 不同時間畫面獨立且貼圖不超取樣、左邊圖層直接拖曳改變疊放畫面、透明填滿/獨立框線、格子位置/檔名/選取回饋、群組時間/刪除與原音、完整影片輸出與原有回歸。iPhone Safari 的實際流暢度、描邊手感與解碼仍待真機。
