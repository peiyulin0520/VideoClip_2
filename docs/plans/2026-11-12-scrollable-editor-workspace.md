# 手機圖層檢視與整頁捲動

使用者錄影顯示：預覽佔大半螢幕、整個編輯器 overflow:hidden、時間軸最多 128px；捲動只發生在小時間軸內，預覽不會退開，底部工具再佔去一段高度。

本次以工作區調整為主，回歸另修復續用設定的儲存競態；專案、素材、字體、Key 與輸出格式沿用原模型：

- 編輯器改為整頁垂直捲動；預覽預設長邊顯示區約 24dvh（140–240px），隨頁面捲走；仍可放大預覽，返回時回到原捲動位置。
- 時間軸按圖層數展開全部列，取消內層垂直捲動。左右仍控制時間/播放頭，保留雙指時間縮放、長按片段移動與修剪。
- 工具欄接在圖層列表下方，正常頁面流，不固定壓住軌道。頁首和播放控制保持可用，提供查看圖層、編輯工具、回到預覽捷徑。
- 未選取的預覽和空白邊可上下滑頁面；選取框本身保留單指拖移及雙指縮放。觸控先點選物件，再從選取框調整，避免第一次滑動誤移素材。
- 圖層 icon 拖到邊緣時捲動外層頁面，不再捲小時間軸；刪除原來每次改 store 都拉回選取列的自動捲動，避免填字時畫面跳走。

驗收：新增 13 層的真實觸控捲頁、末層及工具不互相遮擋、工具/預覽捷徑、編輯輸入不跳回時間軸、左右捲時間與上下捲頁獨立、320px 寬短螢幕及既有直接拖層/字卡/匯出等回歸。使用者錄影僅在 /tmp 分析，不加入 repo。
