本輪承接使用者的定格規則及 23 點追加。前輪 PR #11 已合併，另開新 PR，使用者自行合併。

## 執行順序與驗收

- [ ] A：裁切穩定 canvas、獨立四工具、來源座標縮放、undo/redo、可聽選段、視窗 X 不套用。
- [ ] B：A/B/C 分割刪 B 後轉場保留 C 來源時間；音訊與預覽不中斷回歸。
- [ ] C：暫停菱形選取／白底橘框；明確新增近鄰、按鈕刪所選；位置/色調改所選；四種原地短動作與時長/力道。
- [ ] D：全頁命名、文字 placeholder、圓角/留白/對齊、不收合功能頁籤。
- [ ] E：固定預覽基地與可拖自訂比例；選段左右固定基地。
- [ ] F：多版型、來源點選 popup、子素材命名、起迄連動、短片速率/自訂補色文字、即時示意圖。
- [ ] G：版型群組展開子片段、輪序播完停格、同時/依序圖層、子元素。
- [ ] H：全部 check、Actions 瀏覽器回歸與新截圖、文件/PR 更新。

每個階段更新日誌與交接。影片錄影只在 /tmp 檢視，不進公開儲存庫。
使用者最新要求優先於舊規格：膠囊統一圓角；選段音訊即時可聽；取消以右上 X 且不儲存；定格只有原地短動作不含進出場與轉場。
iPhone Safari 長片、觸控與聲畫效能仍列真機驗收，不以 Chromium 計數代替。
