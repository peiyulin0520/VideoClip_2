# 實際剪輯工作流程：本次需求與驗收

這份計畫依使用者本次明確要求一起實作。沒有另開 PR；工作分支開發、CI 驗收後 main 發布。前一正式版本 c9709ed / 文件 e9ceb54 保留。實際成功狀態看 PROGRESS 快照。

- 留白：可加入主軌的色塊素材（片段可排序、修剪），或可任意放置的色塊圖層；可開自由時間軸，讓影片之間有真正空隙。舊 mainOffset 保留相容，不重設舊專案。
- 素材庫：IndexedDB v3 新增獨立 library，不刪 projects/blobs/userFonts；手動收藏自己的貼圖與畫作，可跨專案重用，刪除收藏不刪原專案的檔案。
- GIPHY：裝置自行輸入 API Key，僅存 meta，不進公開原始碼、專案 JSON、素材庫、日誌或測試截圖。申請說明連到 developers.giphy.com；Create API Key / App / LittleMoments / Web。API 搜尋及貼圖下載使用者於該頁主動操作才連線，顯示 Powered by GIPHY。搜尋結果不收進共用素材庫；放進專案的 GIF 才保留於該專案。
- 動態貼圖：gifuct-js（MIT）解碼透明 GIF，以專案時間驅動預覽與匯出，不用靜態縮圖假裝動畫。
- 裁切：四邊/角落直接拖曳；手動套索描邊，保留框選區、其他透明，隨素材縮放旋轉。不宣稱自動去背或自動追蹤移動的人。
- 記憶：同一台裝置繼續使用不重設字體/專案/收藏；資料存這個瀏覽器，清除網站資料/無痕/換瀏覽器不保證相同資料。GIPHY Key 各裝置獨立。
- 外觀：深色、黑白、清爽白色、薄荷、暖棕，可於設定更改並記住；預覽品質可調，輸出解析度另外決定。
- 字卡裝飾：粗細、距離擴大範圍；新增長度/透明度。自訂顏色以彈出色輪/亮度/RGB 調整，不要求輸入色碼。
- 播放：避免無變動影片貼圖重複上傳、影片原生解碼影格與畫面節奏同步、減少每幀 React 更新，提供 720/1080/1920 預覽。
- 音訊：原片音訊保留、靜音/移除/分離音軌，背景音樂可匯入/拖曳/修剪/調音量；播放與輸出以相同音量/時間/靜音規則混音。
- 完整匯出：優先 WebCodecs + Mediabunny 完整時間軸合成，含文字、遮罩、GIF、留白、配樂。可用時輸出 H.264/AAC MP4；不支援時明確標示 WebM 或即時錄製備援，不把單格 PNG 當影片完成。可取消、顯示進度、下載/系統分享。

驗收包含時間/音訊混音/色彩幾何/資料庫遷移單元測試、GIPHY mock HTTP（不使用真實 Key）、瀏覽器預覽與匯出影格/音軌解析檢查、跨專案素材與重開字體測試及可讀繁中截圖。iPhone Safari/HEVC/HDR/匯出記憶體與聲音解鎖仍列真機驗證，不把 Chromium 模擬當成 iPhone 成功。
