# 群組優先、緊湊選單、素描及偏移剪裁

使用者 2026-11-13 最新 10 點實測。PR #8 已由使用者合併，基線 main ccc85d8；前版 306 單元/114 Chromium e2e 成功。本次另建 PR，仍由使用者自行 Merge。

1. 展開整個時間軸先顯示影像/文字/貼紙/音訊的分類摘要，不直接列全部素材。點分類才展開該類；收合整個時間軸再開會回到分類摘要。新增或明確選取素材時，只展開該類供當下編輯。
2. 以功能列字級為上限：選單/數值/標題/彈出視窗共用 14px，備註 11px；示意圖縮小，特效三欄、版型四欄。保留 44px 觸控範圍，靠字級、間距、圖像與多欄減少佔位。
3. 鉛筆移除實心核心，依來源像素固定的紙紋留下透明空隙與不同濃淡；反覆描畫加深，紙紋不被一條原子筆底線填滿。PNG 及匯出保留顆粒。
4. 移除重複的毛筆，只留感壓筆（可用壓力，否則速度/收筆），其餘圓筆/螢光/點點/鉛筆/橡皮擦不變。
5. 已選手繪的透明畫布允許直接單指拖移，不把觸控交給下層影片；其他透明貼圖的穿透選取保留。以剛新增手繪、沒有先縮放、從透明區起手的真實觸控驗收。
6. 播放列圖示補「預覽／工具／縮小／放大」短標籤，原 aria-label 及功能不變。
7. 參考使用者圖二及另一 VideoClip 的緊湊軸形式，不再為交接＋保留一整列。可見圓圈 18px、觸控目標 44px，置於兩列間、影像交接位置；素材及修剪把手的中心線不被遮住。既有拖曳/修剪/跨軌/復原測試維持，不能重現前版大觸控區擋手勢問題。
8. 裁切保留/橡皮擦/自由描邊均用下方控制圈操控上方瞄準圈。預設偏移 56 CSS px，可調 0–120；筆刷直徑可調，描邊沿上方十字中心。點位先轉換為原素材 UV，畫面/輸出用同一遮罩，控制圈/連線不存入成品。保留逐筆復原、取消與檢查結果。
9. 每個特效選項只保留動畫與名稱，不列應用場景文字；已選框線及上方已用清單保留。
10. 版型預覽靠左，右側依「第 N 格／位置」列素材選單，不要求與預覽格位逐一對齊；移除下面重複的素材列。來源與套用邏輯保持，320px 螢幕不得溢出。

驗收：313 單元（新增 7 紙紋/偏移座標）、120 瀏覽器情境（新增 6）。舊測試明確透過 UI 展開所需群組；舊遮罩幾何情境選偏移 0，新情境驗預設偏移 56、實際觸控、原音/畫面與 PNG/單格輸出。素描以區域濃淡與紙紋空隙驗證，保留真正可見與輸出檢查。Safari 指壓/自由描邊、原生選單與縮小字級焦點、單指拖移及效能待真機確認。
