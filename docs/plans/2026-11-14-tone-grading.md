# 色調頁籤、基礎組合與定格漸變

使用者新增亮度、飽和度、曝光、高光、對比、黑點、鮮艷度等調色，以及黑白片／復古／清新／冷／暖／鮮豔／電影預設。最新更正：獨立功能頁籤名「色調」，不放剪輯；不可拖累播放；第一個菱形定格的色調須平滑過渡到第二個。

## 本輪範圍
- 獨立色調頁籤，可選視覺素材（影像／照片／貼紙／文字）；版型沿用既有整組定格，調色作用整組框架與素材。
- 10項：亮度、飽和度、曝光±2EV、高光、對比、黑點、鮮艷度、陰影、色溫、淡化。中性值在介面為0（淡化0–100），舊brightness/saturation倍率值相容。
- 13組：原色、黑白片、復古風、清新風、冷色調、暖色調、鮮豔、電影風、奶油、日系、森林、夕陽、高對比黑白。參數組合可套用後再調，不累加多層濾鏡；選中框與aria-pressed可見。小圖是靜態合成示意，沒有額外影片解碼／預覽合成器。
- 未有定格時套用整段；按「定格目前色調」記錄，移白線再改色調會寫另一個定格。所有色調數值與舊位置／大小／透明度／色彩一同插值，不插值preset字串。原色／還原僅重置目前色調，不動位置／大小，其他定格不變；刪除沿用既有定格細部調整。存在定格時手動修改先停在當前秒數，避免拖滑桿產生一串移動時間的定格。無定格可播放中直接調整整段。
- 舊專案／舊定格缺新欄位一律中性，首末／中點／trim／split／模板共用相同動畫評估。原片不改，設定隨專案保存／復原。

## 效能與匯出
GradeFilter在既有Compositor單一WebGL pass做曝光／亮度、對比、亮暗部與黑點、淡化、飽和／自然鮮艷、色溫。處理premultiplied alpha後還原，透明範圍不染成實色；舊飽和→色溫順序相容。中性無色調pass；非中性每個sprite重用GradeFilter與同一組typed uniform，只有值改變才更新。GlProgram.from快取同一shader，不每幀建程式／CPU讀像素／新畫布。既有共享影格貼圖與blur資源沿用。

預覽、定格、逐格與即時匯出共用Scene/Compositor評估與shader，不依Canvas2D filter。mediaStats新增colorAllocations/colorUpdates/colorPasses供實測，不能把資源計數當實機FPS保證。Safari真機仍列PLAN §7。
