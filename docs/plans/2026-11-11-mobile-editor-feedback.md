# iPhone 編輯實測：8 項回饋與驗收

本次使用者明確要求一起處理的體驗修正；不視為完成整份 Phase 4–7。

1. 匯入後黑畫面：播放器原只監聽 loadeddata/seeked；補 metadata/canplay/resize、首格 muted priming + requestVideoFrameCallback、最長 120 frame 的暫時重繪。不能用縮圖冒充影片。Chromium 模擬 loadeddata/seeked 缺失與空白編輯器第一次匯入；iPhone Safari 仍待重測。
2. 預覽小、浮動鈕太大：縮小時間軸與面板占高；保留細選取框，刪除所有畫面內縮放/刪除圓鈕。Pointer Events 兩指縮放/旋轉、單指拖移；數值大小/旋轉及刪除放在圖層頁籤。增加全畫面「放大預覽/返回編輯」。
3. 色彩：所有字卡色票下增加原生全色域 picker 與 HEX 色碼（含三碼轉六碼）；保留快速色票。
4. 裝飾距離：Decoration.offset 選填、以字高倍數垂直移動，保留粗細，畫布留白隨路徑重算。舊資料預設 0。
5. 形狀：CardBox.softness/depth 選填；softness 將閉合輪廓的角平滑化，depth 調整凹槽往橢圓輪廓的程度；舊參數保持原路徑，四邊內距/原有圓角仍可調。
6. 多格：拍貼三格、直式膠卷、四格相紙，獨立素材選擇/匯入、固定視窗 cover 裁切。可固定、右滑入左滑出、向上滑過。每格共用全域時間，長度受最短影片限制；第一格有聲、其餘靜音，底層主軌在版型期間靜音。版型替換可復原、不刪原始素材或文字。
7. 清晰度：預覽長邊最多 1920（不超過專案原尺寸）；文字用 2–4 倍點陣貼圖、保持邏輯幾何一致，單卡上限 4096px/8MP、快取 16MP。新字卡不預設模糊陰影；舊卡外觀設定不抹除。
8. 開場：Project.mainOffset/background 選填，主軌可整組延後 0–600 秒，底色黑/白/自訂，時間軸顯示開場區。前段真正無影片，文字可從 0 秒出現。修剪/分割/複製/刪除仍維持 offset，可復原；預覽與單格匯出共用底色。

驗收：227 單元測試；既有 e2e 改為兩指操作，加 5 個回歸 e2e（長修剪/多格綜合流程拆為獨立情境後共 50）與 docs/screenshots/usability/ 新圖。瀏覽器驗收透過 GitHub CI；不能把 Chromium 當作 iPhone Safari 真機。
