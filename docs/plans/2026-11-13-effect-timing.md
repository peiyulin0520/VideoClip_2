# 特效時長、任意起迄與共用成對標籤

- 最新決定：使用者選擇「維持原本總長20秒，在交接前後分配特效時間」。A、B各10秒、特效3秒，預設A尾1.5秒退場、B頭1.5秒進場；不重疊縮成17秒，不借用凍結的首尾影格。影片與原音依原生秒數播放，20秒不變。
- 單素材以B進場、A退場；指定3秒就是片段原時間中的3秒，不等待特效完成才播放。取消舊半片長限制。可用開頭/結尾預設，或在任意秒數設定多組起迄。
- ClipAnimation.ranges為素材本地秒數；Project.transitions/effects.ranges為專案絕對秒數；轉場另存anchor交接基準，兩素材移動時區間跟著交接走。undefined相容舊起/迄預設；[]表示沒有使用區間。舊轉場也採原時間退/進，不再解碼借用另一側靜止影格。混搭效果各自保留區間，同交接同種類仍只一個。
- 特效起迄popup：共用SourceRanges縮圖軸，白線能點選/拖曳/鍵盤定位，小倒三角成對拖動；直接輸入起點/終點/時長；白線新增必定有對應終點；各組可刪，局部復原與取消。A/B交接標出A起點和B結束本地秒數及總時長。頁面說明總長不變。
- 真實合成預覽▶/⏸與狀態色、白線跟播放同步；草稿只提供Player暫時Project，不進持久化/專案復原，取消還原原時間與專案；套用一次進專案歷史。修正ProjectPreview畫布漏ref問題。
- 來源修剪、音訊、模板來源與特效沿用同SourceRanges與新增配對演算法。修剪可移除最後一組、禁止空選區誤套回完整影片；模板可空選表示全程補色。音訊舊快捷起點立即建立終點，後續終點按鈕只細調既有成對區段。
- 單素材出場推移與進場方向有別；wipe、分格、膠卷、zoom等保持共用預覽/匯出幾何。沒有額外改變速度或音訊偏移。

驗收：本機check及GitHub Actions完整Chromium回歸，新增10秒動態紅綠/440Hz自製片驗影片在特效內前進、保留10秒及原音；兩支10秒維持20秒；不對稱A/B、任意區間、多組新增/刪除最後一組/復原/取消/重開、影片特效與共用修剪。Safari觸控、解碼及長片順暢仍待真機。
